# Teachers’ Day Letter — Randy Bello

A polished, responsive Teachers’ Day letter dedicated to Randy Bello from Justine Paul Sumayang. The project includes Randy’s supplied portrait and a warm appreciation message.

## Project files

- `index.html` — letter content and page structure
- `style.css` — responsive layout, typography, colors, and print styling
- `script.js` — subtle entrance animation and print interaction
- `randy-bello.jpg` — supplied portrait used in the photo panel

## Features

- Elegant navy, ivory, and warm-gold visual theme
- Personalized Teachers’ Day message for Randy Bello
- Responsive layout for desktop and mobile
- Subtle page and text entrance animations
- **Print / Save as PDF** button

## How to use

1. Extract the project ZIP.
2. Keep all five project files in the same folder.
3. Open `index.html` in a modern web browser.
4. Select **Print / Save as PDF** to print the letter or save it as a PDF.

The page uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
